# Current Calendar System

Observed on June 13, 2026 from the primary Google Calendar.

## Existing Conventions

- Work, study, health, personal, household, and travel events share the primary
  calendar.
- Semantic grouping is expressed through concise Russian titles and occasional
  leading emoji rather than separate calendars.
- The calendar contains both fixed commitments and protected execution blocks.
- Todoist-like actions sometimes appear inside event descriptions.
- Travel plans already include transfers, meals, rest, and itinerary blocks.
- Some household routines are all-day recurring events.

## Preserve

- One primary timeline for conflict detection.
- Concise titles and useful emoji.
- Descriptions with preparation context, links, checklists, or expected result.
- Explicit rest and transfer blocks in demanding schedules.
- Protected study and work sessions near real deadlines.

## Improve

- Put physical addresses in the Calendar `location` field, not only in the
  description.
- Avoid vague blocks containing unrelated actions.
- Break very long cognitive sessions into focused blocks with recovery.
- Keep actionable task state in Todoist and use Calendar only to protect time.
- Add buffers around appointments, flights, classes, and unfamiliar routes.
- Use Todoist context labels to exploit transit, waiting, and route adjacency.

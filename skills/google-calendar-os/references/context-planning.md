# Context Planning

## Window Matrix

| Window | Suitable work | Avoid |
|---|---|---|
| Bus/train passenger | `📱 Телефон`, 10–30 min, low privacy needs | Deep work, calls in noisy transport |
| Taxi/car passenger | Short phone review or messages | Anything causing motion sickness or privacy risk |
| Driving/cycling | Nothing except passive navigation/audio | All interactive tasks |
| Queue/waiting room | Phone tasks up to the reliable wait estimate | Tasks that cannot be interrupted |
| Cafe/library | Laptop-safe computer or deep work | Sensitive work on insecure networks |
| Home/office desk | Deep work and computer tasks | Route-dependent errands |
| Existing destination | Nearby physical errands | Detours that threaten the next commitment |

## Geographic Batching

1. Normalize each physical task to a place or area.
2. Anchor the day around fixed destinations.
3. Find errands near those anchors or along the direct route.
4. Prefer one cluster with several errands.
5. Include opening hours, carrying load, weather, and return logistics when
   relevant.
6. Reject a batch if the travel uncertainty consumes the lateness buffer.

## Energy Matching

- High energy: deep work, difficult study, architecture, writing.
- Medium energy: multimodal operations, reviews, planning, administration.
- Low energy: messages, calls, quick checks, simple purchases, packing.
- After travel, exams, medical visits, or long social events, reduce cognitive
  load and preserve recovery.

# Hermes MCP Ecosystem Guide

Практический обзор самых полезных MCP-серверов для Hermes Agent.

---

# Что такое MCP

MCP (Model Context Protocol) — это способ подключать внешние инструменты к AI-агенту.

Проще говоря:

* Gmail становится инструментом
* Google Calendar становится инструментом
* GitHub становится инструментом
* Browser становится инструментом
* PostgreSQL становится инструментом

После подключения Hermes может использовать эти системы самостоятельно.

---

# Практический принцип

Не подключать всё подряд.

Большинство пользователей сначала ставят десятки MCP-серверов, а потом оставляют только несколько действительно полезных.

Хороший AI-агент обычно использует:

* 5–10 основных MCP
* 2–5 дополнительных под конкретные задачи

---

# Top MCP для разработчика

## 1. GitHub MCP

Возможности:

* чтение репозиториев
* поиск кода
* просмотр PR
* просмотр CI/CD
* создание issue

Пример:

"Найди все TODO связанные с auth"

---

## 2. Filesystem MCP

Возможности:

* чтение файлов
* запись файлов
* поиск по проекту

Фактически является обязательным.

Без него агент почти слепой.

---

## 3. Playwright MCP

Возможности:

* запуск браузера
* тестирование интерфейсов
* заполнение форм
* UI automation
* E2E проверки

Пример:

"Проверь форму регистрации"

---

## 4. PostgreSQL MCP

Возможности:

* выполнение SQL
* анализ схемы
* просмотр данных
* поиск проблем с БД

Пример:

"Покажи последние 100 пользователей"

---

## 5. Context7 MCP

Дает агенту актуальную документацию.

Особенно полезен для:

* React
* Next.js
* Docker
* PostgreSQL
* Go
* TypeScript

---

## 6. Memory MCP

Постоянная память между сессиями.

Позволяет помнить:

* проекты
* архитектурные решения
* договоренности
* предпочтения

---

## 7. Docker MCP

Возможности:

* просмотр контейнеров
* просмотр логов
* рестарт контейнеров

Пример:

"Проверь контейнер api"

---

## 8. Kubernetes MCP

Возможности:

* просмотр pod
* просмотр deployment
* диагностика кластера

Пример:

"Почему pod находится в CrashLoopBackOff"

---

## 9. Notion MCP

Возможности:

* поиск документов
* создание страниц
* обновление баз данных

---

## 10. Slack MCP

Возможности:

* чтение сообщений
* отправка сообщений
* создание отчетов

# Skills + MCP

Самая сильная архитектура выглядит так:

MCP = инструменты

Skills = workflow

Пример:

MCP:

* GitHub
* PostgreSQL
* Browser

Skill:

release-check

Внутри skill:

1. Проверить CI
2. Проверить миграции
3. Проверить healthcheck
4. Сформировать отчет

Таким образом skills не заменяют MCP.

Они оркестрируют MCP.

* Filesystem

Главная идея Hermes не в количестве MCP.

Главная идея — подключить несколько действительно полезных инструментов и построить вокруг них ежедневный workflow.

## Правила формата для агента и навыков

Пишем под **самый бедный канал клиента**. Если хоть один его канал — VK:

- никакого `**жирного**`, `# заголовков`, таблиц и блоков кода в ответах;
- структура — эмодзи-маркеры блоков (`📅`, `✅`, `⚠️`), списки через `•` или `1.`;
- длинные ответы — короче 3 500 символов, иначе VK режет сообщение посередине;
- ссылки — голым адресом.

Навык `daily-briefing` уже написан так. Общее правило вписано в `soul-rules.md` (раздел «Формат ответа»).

## Как добавлять канал в реестр

1. Подключить на тестовом/эталонном сервере по плейбуку.
2. Прогнать проверки по строкам таблицы: доступность с сервера, Markdown (отправить ответ с `**`, списком и таблицей),
   кнопки подтверждения, длинное сообщение > 4 000 символов, вложение, голосовое, доставка cron.
3. Перевести строки из 📄 в ✅/⚠️/❌ с датой; оговорки — в раздел канала ниже.

## Заметки по каналам

**VK.** Путь к настройкам: Управление → Дополнительно → Работа с API. Ключу нужны права
«Управление сообществом» и «Сообщения» (только «Сообщения» → `error 15`). События Long Poll:
`message_new`, `message_edit`, `message_event`; галочка в интерфейсе может не сохраниться —
включаем через `groups.setLongPollSettings` (плейбук, шаг 10). Доступ — только по списку ID
(`VK_ALLOWED_USERS`, `VK_ACCESS_POLICY=user_only`). Отдельную беседу создавать не нужно — бот работает в
личных сообщениях сообщества.

**Веб-интерфейс.** Вход по логину/паролю при публичном адресе; `/api/status` открыт намеренно.
Чат устроен как терминал: Playwright не набирает в нём кириллицу посимвольно — для автотестов только латиница.

**MAX.** Плагин в каталоге Hermes: polling или webhook (webhook требует публичный HTTPS и порт 8646 —
на общем сервере клиента используем polling). Список разрешённых пользователей плагина **не учитывает**
одобрения через pairing Hermes — только свой allowlist.

**Telegram.** С российского сервера — только через прокси вне РФ; для клиентов с ПДн не предлагаем.
